

# GRE Tunnels

## Overview

This lab demonstrates how GRE tunnels can provide logical point-to-point connectivity between remote networks.

## Objectives

* Configure GRE tunnel interfaces
* Configure tunnel source and destination
* Assign tunnel IP addresses
* Configure routing through the tunnel
* Verify connectivity

## Tools

* Cisco Packet Tracer
* Cisco IOS

## Outcome

Successfully established and verified a GRE tunnel between network devices.
